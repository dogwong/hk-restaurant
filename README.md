# hk-restaurant

Run your restaurant at a Hong Kong pace.
*fast and efficient.*

latest-original.js -> source file\
latest.js -> modified file

Current version: 5700

### How to use
Enable Content Overrides
1. Open up DevTools in the restaurant page
2. Go to Sources tab in the top bar, Page tab in the side bar
3. Under the "top" item, find "newdemo2/" folder
4. Open the game folder which name starts with "app"
5. Open "newdemo2"
6. Right-click on the file named Streetscene.js and select Override content
7. Finish the setup if you have never used the Override content function before

Content Overrides already enabled
1. Save the game first and close the tab
2. Copy the content from latest.js and paste it into Streetscene.js*
* File name should end with a number
* On Windows, the name ending should look like ".js%3F5627", On MacOS, ".js?5627"
3. Save the file and launch the game
